# IRIX-UNIT — нормативная себестоимость

Автор — Ирина Романова, IRIX.

Калькулятор себестоимости мебельной продукции. Разворачивает многоуровневую спецификацию (BOM) до закупаемых материалов, сопоставляет их с прайс-листом, добавляет расходы по ОПиУ и услуги маркетплейса — на выходе цена продажи по каждой модели и сводная картина по всей компании.

Работает как один самостоятельный HTML-файл: не требует сервера, открывается в браузере. Данные хранятся в общем облачном кеше — все, кто открывает файл по одной ссылке, работают с одними и теми же цифрами.

---

## Режимы работы

Переключаются кнопками в шапке.

### 1. Калькулятор

- **Модель / изделие** — поиск по подстроке (набираете часть названия — выпадает список совпадений с подсветкой).
- **Характеристика** — цвет/вариант отделки, подставляется по выбранной модели.

После выбора видно:

- **Раскладка по материалам** — все закупаемые материалы, их количество на изделие, цена и сумма. Материалы без цены — строки с полем ввода: вписали цену → нажали ✓ → она сразу ушла в общий справочник и подставилась во всех спецификациях, где встречается этот материал.
- **Себестоимость изделия**:
  - Прямые затраты материалы — сумма из раскладки;
  - Расходы по ОПиУ на единицу — все статьи расходов, делённые на плановый общий выпуск;
  - Услуги маркетплейса — считаются, только если включён признак «Маркетплейс» (см. ниже);
  - Итого себестоимость = материалы + расходы ОПиУ на единицу + услуги маркетплейса;
  - Итого на плановое количество — себестоимость единицы × плановое количество этой модели в выпуске.
- **Цена продажи** (открыто по умолчанию) — маржа, коммерческие расходы, НДС → рекомендуемая цена с НДС и без.

### 2. Справочник цен

Все материалы, для которых нет цены в прайс-листе, — одним списком, отсортированы по частоте использования в спецификациях (сверху — те, что дадут наибольший эффект). Поиск, поле цены, ✓ для сохранения. Заполняется независимо от того, какая модель сейчас открыта в калькуляторе.

### 3. Выручка компании

Сводная картина по всей компании, отдельно от конкретной модели:

- **Общая выручка** и **доля маркетплейсов, %** (остальное — опт/прямые продажи) → выручка по каждому каналу.
- **Себестоимость** — % от выручки (материалы на реализованный объём).
- **Услуги маркетплейса** — выручка маркетплейсов × та же ставка %, что задана в калькуляторе.
- **Все остальные расходы** — сумма статей ОПиУ, всегда видна одной строкой; кнопка «Показать по статьям» разворачивает детализацию (те же значения, что и в калькуляторе, — правки в одном месте видны в другом).
- **Прибыль** и **рентабельность**.

### 4. Загрузка данных

- Загрузка новых файлов «Развёрнутая спецификация» и «Цены закупки» (.xlsx, тот же формат, что и раньше) → пересчёт разворачивает BOM и сохраняет результат в общий кеш. Нужны сразу оба файла.
- Экспорт снимка (.xlsx с текущими правками цен, расходами ОПиУ и сводом по моделям) — для пересылки или ручной выгрузки на Google Диск. Автоматической синхронизации с Google Диском нет — статичный HTML-файл не может безопасно хранить OAuth-ключи Google.

## Расходы по ОПиУ

Список статей — на панели «Расходы по ОПиУ» под калькулятором. Значения предзаполнены по вашему отчёту, но это стартовые цифры — редактируйте под текущий месяц. Та же таблица используется и на вкладке «Выручка компании».

**Логика:**

```
Расходы на единицу = (сумма всех статей ОПиУ) ÷ Плановый общий выпуск (все модели, шт/мес)
Итого себестоимость = материалы + расходы на единицу [+ услуги маркетплейса]
Итого на партию = Итого себестоимость × плановое количество этой модели
```

«Плановый общий выпуск» — это выпуск по всей компании, не по одной модели: расходы общие, делятся на общий объём.

---

## Услуги маркетплейса

Не входят в общий пул ОПиУ — считаются отдельно, только для моделей с включённым признаком «Маркетплейс»:

```
Услуги маркетплейса (в калькуляторе) = Цена маркетплейса (вводится вручную по модели) × Ставка, %
Услуги маркетплейса (в выручке компании) = Выручка маркетплейсов × та же Ставка, %
```

Ставка — единая, задаётся один раз и используется в обоих местах; по умолчанию 55%, ориентировочно посчитана по вашим данным (комиссия + логистика + хранение + продвижение + эквайринг и пр. в сумме к выручке маркетплейса). Цена маркетплейса — своя у каждой модели.

Если признак выключен (опт/прямые продажи) — эта строка не считается, расходы идут только из общего пула ОПиУ.

## Где хранятся данные

Всё — через `window.storage`, общий (shared) кеш, привязанный к этому файлу-артефакту:

| Ключ | Что хранит |
|---|---|
| `uploaded-products` / `uploaded-unmatched` | Спецификации + цены после последней загрузки во вкладке «Загрузка данных» |
| `price-overrides` | Цены, вручную дозаполненные в калькуляторе или справочнике |
| `opex-values` | Текущие суммы по статьям ОПиУ |
| `global-settings` | Плановый общий выпуск, признак «Маркетплейс», ставка % услуг маркетплейса |
| `calc:<модель>` | Плановое количество, маржа, коммерческие расходы, НДС и цена маркетплейса — отдельно по каждой модели+характеристике |

Вкладка «Выручка компании» использует значения из `global-settings` и `opex-values` — отдельно ничего не хранит.

Если ни разу не загружали свои файлы — используются данные, зашитые в файл при последней сборке (снимок на момент создания).

**Важно:** хранилище общее — его видят и могут менять все, у кого есть ссылка на файл. Приватных, персональных цен здесь нет. Отдельного логина/пароля в файле нет.

## Известные ограничения

- Расчёт себестоимости материалов зависит от точности сопоставления названий в спецификации и прайс-листе — расхождения в написании (регистр, лишние пробелы, синонимы) видны в разделе «Справочник цен» как позиции без цены.
- Ставка услуг маркетплейса и её база (совокупные расходы / выручка), доля маркетплейсов в выручке и % себестоимости на вкладке «Выручка компании» — усреднённые оценки по вашим историческим данным, не точный расчёт текущего месяца. Поправьте под актуальные цифры.
- Загрузка новых файлов и XLSX-парсер (SheetJS) требуют интернет-соединения; сам калькулятор, справочник цен и вкладка «Выручка компании» без него работают.
- Все расчёты ориентировочные и не заменяют бухгалтерскую калькуляцию.
