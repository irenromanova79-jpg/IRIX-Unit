Загрузка по ссылке

Вместо выбора файла вручную — прямая ссылка на .xlsx (например, raw-ссылка на файл в GitHub). Работает только со ссылками с CORS-доступом: raw.githubusercontent.com подходит, обычная ссылка на просмотр в Google Диске — как правило, нет.

Экспорт снимка данных

Скачать .xlsx с текущими правками цен, расходами ОПиУ и сводом по моделям — чтобы переслать, положить на Google Диск или свериться вручную

Автоматической выгрузки на Google Диск из статичного HTML-файла нет — Google требует OAuth-авторизацию, которую нельзя безопасно встроить в файл, открываемый в чужом браузере. Но: пока файл открыт по одной и той же ссылке, все правки цен и расходов уже общие для всех, кто по ней заходит (см. статус выше) — Диск для этого не нужен. Эта кнопка — для отдельного снимка на скачивание: сохраните .xlsx и загрузите на Диск вручную, если нужна версия «на всякий случай» или для отправки тем, у кого нет доступа к файлу.
